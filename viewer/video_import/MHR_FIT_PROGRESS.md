## 本轮结论

每次联合拟合现在记录执行进度、分项验收、输入/输出/代码哈希、未完成项和下一步。**执行完成、保存参数回放一致、真实拟合验收是分别记录的状态**；没有依据时不输出整体拟合百分比。

现有 9 段是同机位、同衣着、同镜面、开始时间相隔 10 秒的近连续练习。固定 36 帧复核以单手正手形态为主，没有可靠确认完整反手；正式动作标签仍为 unknown。它们没有构成 9 个独立相机视角或已标注的正反手数据集。

穷举 511 个非空视频组合后，精选 **4 段：48.53、49.23、49.33、50.03** 能保留现有 9 段的 **99.258% 面支持、99.670% UV 支持代理**。这是已有观察范围的保留率；四段纹理未重新合成，不能推导与九段相同的颜色质量、真实三维精度或“人体拟合完成 99%”。

建议下一轮以 **4 个动作片段 + 2 个辅助片段** 为初始目标：正手两个角度、反手两个角度、慢转身、握柄/拍面近景。已有合格正手可以复用。**不能给出“至多若干段就完全拟合”的上限**：看不到的接触、模糊的拍面、未标定尺度，不会由重复同机位录像自动解决。数量按验收缺口调整。

## 每次运行如何记录

`run_fullbody_refit.py` 自动接入 `mhr_fit_progress.py`。检查输入、云端调度、运行、下载验证、失败和传输中断均留下记录；连接中断时保留远端可能继续执行的状态，不能据此记作 GPU 计算失败或完成。

- 每个拟合输出目录：`completion.json`，当前快照。
- `progress_attempt.json`：绑定当前尝试的输出目录、run ID 与远端 job ID；恢复记录沿用同一运行身份，新尝试排除旧候选/报告。
- 总台账：`output/mhr_fit_progress/ledger.json`，每个 run 最新状态与历史事件索引。
- 历史事件：`output/mhr_fit_progress/events/<content_sha256>.json`，独立保留，重复相同内容不会创建第二份事件。
- `execution`：pending / needs_input / failed / transport_pending / completed / unknown。
- `acceptance`：not_assessed / rejected / needs_review / accepted_joint_fit。原生回放审计使用独立事件类型和 not_applicable，不计入通过联合拟合数。
- `stages`：每个阶段分别 passed / failed / not_completed / unknown；执行优化阶段可为 completed。
- `provenance`：视频、原生档案、候选、实际报告、优化代码及记录器哈希；无法恢复的旧版本身份保持 unknown。
- `unfinished_items` / `next_steps`：用于排下一轮实施任务。标准尺寸继续记为 assumed，不变成实测。

台账是本地私有产物，位于已忽略的 `output/`，不会作为数据上传到 Git。工作代码、方法、历史结论与数量证据摘要随 Git 保存；迁移时需单独备份台账、源报告及输入档案。台账事件保留本地运行历史，不是不可篡改的外部审计服务。

### 当前验收维度

| 分项 | 如何确定完成 | 当前局限 |
| --- | --- | --- |
| 输入准备 | 当前视频关键帧、尺寸来源、训练/留出划分可追溯 | 自动轮廓允许临时实验，仍未人工验证 |
| 原生 MHR 回放 | 模型/参数/坐标一致，误差通过已有门槛 | 只证明能重现保存的网格 |
| 相机一致性 | 拟合与观测使用同一套 root/focal/坐标 | 保留预测相机不等于物理标定 |
| 跨视频身份 | 同一人物共享 shape/scale 的优化与留出验证 | 当前 solver 锁定 shape/scale，尚未实现 |
| 相机/尺度标定 | 独立尺度参考、相机与镜面几何验收 | 标准球拍假设和单目 root 不能替代 |
| 人体不退化 | 位移 P95 < 0.03 m；另需独立人体观察 | 相对原预测的位移门槛不是真实姿态误差 |
| 留出球拍投影 | 同一留出误差 after < 0.9 × before | 当前自动轮廓不是人工真值 |
| 球拍方向/抖动 | 有向柄轴、拍面及时间稳定性独立验收 | 拍框轮廓可能存在方向歧义 |
| 手部网格接触 | 手指与拍柄表面接触/穿透检查通过 | 当前是掌点与关节圆柱代理 |
| 实测尺寸与握柄棱位 | 尺寸来源、物理棱位有清晰证据 | 暂无实测，握柄方式仍需复核 |
| 多角度人工复核 | 正/背/左右/斜视的手、柄、框一致 | 当前尚未作为通过的验收报告 |
| 候选完整性 | 源视频/档案/候选 hash 一致，文件已取回 | 不自动发布候选到主 Viewer |

当前严格 `accepted_joint_fit` 要求完整阶段通过。未来若仅验收“可用于某动作教学的预览”，应新增明确的验收范围和限定结论，不能删除未完成项来获得完整通过。

## 下一轮实施顺序

1. **先补证据**：复核现有正手；优先采握柄/拍面近景、反手前斜与侧视。拍柄底、拍喉、拍框两侧及 MCP/PIP 都要看清。明确单手/双手反手；双手反手不能套用当前右手单握模块。
2. **补人体外观**：同衣着同光线慢转身，手臂稍离身体。用于共享身份与 UV，不把先后拍摄当同次挥拍的同步观测。
3. **共享身份拟合**：建立 person/session/camera 分组，用跨片共同 shape/scale、逐片相机、逐帧姿态拟合；先在清晰慢姿态初始化，再推广到快速击球。保持真人与镜中解剖 ID、一致拓扑及有效帧标记。
4. **握柄接触**：先有向拍面/杆轴与清晰人工关键点，再加入手部表面接触、穿透和双手职责约束。无实测继续输出假设尺寸下的候选，物理棱位不宣布已验证。
5. **重拟合与对照**：原生回放先通过；同一冻结训练/留出协议下优化，记录每次 completion。失败继续保留旧 Viewer；先检查拍面方向，再处理时序稳定性，避免仅靠平滑掩盖错误方向。
6. **再融合纹理**：共享几何通过后重投影取色，统计正/背/侧与手部覆盖、固定留出颜色残差和接缝。未观察区域保留未知，不以生成填充冒充视频观测。

### 初始采集预算

| 角色 | 数量 | 建议长度 / 内容 |
| --- | ---: | --- |
| 正手前斜与侧视 | 2 | 各 12–20 秒，阶段慢停 + 3 次正常动作；合格旧片可复用 |
| 实际反手类型前斜与侧视 | 2 | 各 12–20 秒，明确单手或双手 |
| 慢转身 | 1 | 20–30 秒，正/背/左右，人物和脚完整 |
| 握柄/拍面近景 | 1 | 20–30 秒，掌侧/背侧/边侧、柄底和拍框 A/B |

这是约 88–140 秒的六个目标角色。若同时研究单手和双手反手，初始再补另一种反手两角度，预算变为八段。两个相机同步拍摄需分别记录动作组与文件数，并验收同步/内外参；其收益不能以单纯文件数量比较。当前生成会归一化到 25 fps，未来提高拍摄帧率也要同步完善保留时间轴的导入流程。

### 何时停止增加视频

把已独立复核的正/反手关键阶段、正背侧纹理和手/拍面观察冻结为验证集；不能用新增训练片重新定义原有分母来宣称改善。每轮报告新增有效表面、遮挡位置、投影残差、手部接触/穿透、拍面角速度异常和未通过项，分别比较各动作与视角。

建议试行停止采集条件：连续两次**针对缺口**的新增片，实际 UV 覆盖各增量 <0.5 百分点且固定留出残差改善 <5%，同时所有目标动作/方向/接触验收通过。0.5 pp / 5% 是待验证的实施阈值，不是当前已经验证的规律。若颜色收益趋于饱和但握拍未通过，应继续补握拍证据或改求解器，不能把整体拟合标成完成。

## 方法边界与参考

SAM 3D Body 官方定义为单图人体网格恢复，支持关键点/遮罩提示；它提供逐图的估计，不直接给出本项目跨视频联合拟合已经完成的证明。[官方 SAM 3D Body](https://github.com/facebookresearch/sam-3d-body)

MHR 将身份、姿态和表情参数分开并支持可微优化。因此本项目可以实现跨视频共享身份，但仍需建立并验收对应的损失与观测。[官方 MHR](https://github.com/facebookresearch/MHR)

HumanNeRF 展示了单目视频的新视角合成，也明确涉及输入没有展示的视角细节与非刚性形变。它证明这类合成有研究可行性，没有为本项目承诺若干正反手片即可真实还原全部人体。[HumanNeRF 项目与论文](https://grail.cs.washington.edu/projects/humannerf/)

本轮数量建议来自当前固定观测子集分析和目标缺口，是项目实施建议，不是上述论文给出的最小/最大视频数。
