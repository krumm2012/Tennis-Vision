# 人物 UV 色块与接缝优化调研

调研日期：2026-10-04。范围：九段网球人物视频、现有 MHR 动态网格与 Blender 交付；本轮只研究，不改动纹理、模型或验收版本。

## 结论与项目依据

优先尝试 **可靠对应区域的颜色校正 → 接缝窄带融合 → 材质与拍摄光照分离**。这些方法分别解决色调不一致、边界突变和阴影被烘进颜色图的问题；提高纹理尺寸不能替代它们。肩背可靠区域可先进行光度对照实验，手部几何/遮罩问题继续单因素定位，无须等全人体几何完美后才开展任何颜色实验。

当前 4K 的观测覆盖率为 98.5282%，但留出颜色误差与 2K 基本持平，且逐角 UV 导出误差为零。上一轮收紧可见性使覆盖率由 98.5271% 降至 95.7316%，未通过验收。以上是项目实测，不是这些文献方法的效果。[Blender 交付记录](../../output/blender_nine_clips_20261004/README.txt)、[上一轮实验报告](../../output/offline_iterations/20261004_uv_visibility_v1/REPORT.txt)。

本地代码已有邻面 Potts 标签一致性和每段固定 BGR 增益，最终仍为每面选择一个主要来源、部分纹素使用备选来源；尚无 global/local seam leveling。Blender 已启用平滑着色，颜色图采用 sRGB。因此，建议是在现有一致性选择上增加光度和接缝处理，而不是把问题归结为未开平滑或完全独立的逐面选择。[纹理融合代码](multivideo_texture.py)、[Blender 导出代码](export_blender_body.py)。

## 可用方法及优先级

| 方法 | 针对的问题 | 本项目建议 | 主要限制 |
|---|---|---|---|
| 连贯来源区域选择与异常观测降权 | 相邻小面频繁更换照片产生碎色块 | 改进已有标签平滑，优先同一清晰来源覆盖连续肩背/手臂区域；保留来源记录 | 错误几何、遮挡和衣物错投影不能靠统一来源消失 |
| Global seam leveling，全局接缝颜色校正 | 同一块皮肤或衣服忽明忽暗、偏色 | 可靠重叠区域估计有界颜色修正，再沿网格邻接平滑 | 不应跨皮肤/衣服真实边界强行拉成同色 |
| Local seam leveling / Poisson 融合 | 已基本对齐但接缝仍可见 | 只处理来源切换和真正 UV 接缝附近的窄带 | 无法修正双轮廓；边界条件错误会扩散错误颜色 |
| 多频段融合 | 大面积明暗变化与细纹理同时存在 | 低频平滑得较宽，高频保留清晰来源；作为 Poisson 的对照路线 | 必须先对齐；全图平均仍可能产生重影 |
| 逆渲染，分离反照率/材质/照明 | 旧阴影跟着身体移动，新灯光下仍像贴照片 | 后续共享规范姿态材质，结合逐帧几何估计拍摄照明 | 动态人体需适配；不能将静态多视角工具直接套用 |
| 多视角生成式贴图 | 未观测区域缺纹理，希望更完整、好看 | 可做明确标识的外观增强候选 | 可能补造细节、改变服装和人物特征，不能当测量真值 |

前四行的算法依据见下列一手资料；“本项目建议”和适配限制是结合现有数据的工程判断，尚未证明效果。

### 1. MVS-Texturing / OpenMVS：最贴近当前问题

作者的 MVS-Texturing 接收与三角网格注册好的照片。其全局步骤建立接缝颜色差约束，求每个顶点与来源标签的 RGB 修正，并加入邻接平滑正则；它不是简单给每个区域一个统一增益。局部步骤统一边缘颜色，只在原图区域的边界带内融合。代码中边界带默认值为 20，但不应直接作为本项目不同分辨率的最佳参数。[作者仓库](https://github.com/nmoehrle/mvs-texturing)、[全局校正实现](https://github.com/nmoehrle/mvs-texturing/blob/master/libs/tex/global_seam_leveling.cpp)、[局部边界实现](https://github.com/nmoehrle/mvs-texturing/blob/master/libs/tex/local_seam_leveling.cpp)。

OpenMVS 的实际源代码提供 `GlobalSeamLeveling`、`LocalSeamLeveling` 和 `PoissonBlending`，可作为另一个成熟实现参考。官方自动生成的管线文档有概括，实施应以源代码为准。[OpenMVS SceneTexture.cpp](https://github.com/cdcseacave/openMVS/blob/develop/libs/MVS/SceneTexture.cpp)。

对本项目的迁移应使用现有每帧动态网格，将观测对应到同一规范 UV，再处理真实表面邻接。九段不同动作不能作为一个静止刚体的九组照片直接送入传统 MVS。UV 图上挨近的两个岛也可能在身体上相距很远，不能直接整张图模糊。这是对上述网格注册前提的适配判断。

### 2. 多频段融合：减少色块且保留细节

Burt 与 Adelson 的原始论文把图像拆成不同空间频段，以不同宽度的过渡带合成：宽尺度明暗可平缓变化，细节用更窄的过渡。论文也解释了单一宽度混合在边界可见和双重影像之间的矛盾。[原始论文](https://cs.nyu.edu/~fergus/teaching/comp_photo/readings/spline83.pdf)。

工程上可以将它用于已对齐的规范 UV 观测，但需要表面/区域掩码，保护衣缘、指缝和皮肤边界。不要将锐度下降误判为质量提高；也不要在未对齐的手指纹理上宽范围平均。

### 3. 材质与光照分离：改善重新打光后的真实感

nvdiffrec 从多视角图像联合估计网格、空间变化材质和环境光，输出可用于常规渲染器的三角网格、二维材质贴图及 HDR 环境光，官方代码存在。其效果和输出格式适合研究 Blender 的后续材质流程，但现成示例并非本项目动态 MHR 人物的直接实现；应优先固定已验证几何，研究共享材质和拍摄照明，而不是同时放开所有参数。[NVIDIA 项目页](https://nvlabs.github.io/nvdiffrec/)、[官方代码](https://github.com/NVlabs/nvdiffrec)。

更接近人体的 RANA 面向未知光照下的单目短视频，利用粗几何、法线/反照率和球谐光照，并使用合成数据训练。其官网可见论文、视频、数据入口，本次未核验到即用代码；这是原理参考，未在当前九段 MHR 验证。[RANA 官方项目](https://nvlabs.github.io/RANA/)。

Relightable Neural Actor 有官方代码，利用动态表面与 UV 上的材质、法线和可见性进行重照明；其已知静态光照下的多视角视频输入，与当前非同步九段及镜面观测不同，不能直接宣称可复用论文效果。[官方代码与输入说明](https://github.com/dluvizon/relightable-neural-actor)。

### 4. 生成式补纹理：适合外观增强，需保留来源区分

TexFusion 使用网格和文字条件生成 UV 纹理，通过多视角潜变量同步提高一致性；作者明确说明部分设置会补造材质细节，也可能降低干净程度。因此可作为更完整外观的研究方向，不能保证恢复视频里本人真实皮肤、衣物图案或未观测细节。官网本次未提供可确认的官方代码入口，不把它列为即装即用插件。[TexFusion 官方项目](https://research.nvidia.com/labs/toronto-ai/texfusion/)。

若试用类似方法，应保留观测贴图、修正贴图和生成区域掩码；先锁定脸、服装边界及可见图案，以同一组多视角渲染检查一致性。该约束流程是本项目建议，不是 TexFusion 已提供的功能承诺。

### 5. Blender 侧的接缝修补

Blender 的烘焙 Margin 可通过 Extend 或 Adjacent Faces 填充 UV 岛边缘，减少纹理过滤和 mipmap 导致的细缝。它适合解决细线，不会修复大片来源色差；也不会从现有带阴影颜色图自动恢复反照率。[Blender 官方烘焙文档](https://docs.blender.org/manual/en/latest/render/cycles/baking.html)。

后续可分别调皮肤、衣物的材质响应，但应先处理颜色图上的拼接；凭空增加法线、位移或高频锐化，不构成几何/皮肤细节的测量恢复。

### 6. 可直接试小样的图像工具

Adobe Substance 3D Sampler 的 Equalize 可调整局部对比差异，提供半径、颜色溢出、局部细节和自定义掩码控制；Delight AI 用于减弱 base color 中的阴影和高光。可先用肩背等单一区域做视觉小样，但本项目尚未验证这些滤镜。不同皮肤/衣物 UV 岛不能当作一张普通可平铺材质，直接整图自动均色。[Equalize 官方说明](https://experienceleague.adobe.com/en/docs/substance-3d-sampler/using/filters/adjustments/equalize)、[Delight AI 官方说明](https://experienceleague.adobe.com/en/docs/substance-3d-sampler/using/filters/tools/delight-ai-powered)。

## 推荐下一轮实验

1. 固定 2K、几何、相机、来源和训练/开发留出分组，选已可靠对应的肩背区域；手部继续拆分法线筛选、深度容差及高分辨率遮罩对应的实验。
2. 分别输出基线、仅有界颜色校正、颜色校正加窄带 Poisson、多频段融合候选。保留原图采样值和修正量，定位改善来自哪一步。
3. 报告同一留出集误差、覆盖率、真实表面接缝代理、衣缘/皮肤边界锐度，并用相同 Blender 姿态、相机和灯光对照。接缝代理并非真值，不能靠全图模糊赢分；观测覆盖也不等于准确率。
4. 最终验收补充未用于调参的帧。现有留出已反复用于开发，不能再称最终独立测试。
5. 进入材质/光照分离时，评价应将材质在估计拍摄光照下重新渲染，与留出原图比较；不能直接把去光照后的反照率与带阴影原视频 RGB 做误差。另用新灯光检查旧阴影是否仍粘在人物上。

本轮已核验方法和适用前提，没有运行新贴图优化，没有量化承诺可改善多少。
