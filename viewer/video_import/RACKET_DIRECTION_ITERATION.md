# 拍柄关键点、有向法线与手部方向冲突：第二轮

2026-10-01。本轮复用已校验的双 SAM3D / SAM2 数据，不重复执行人体云推理。新视频自动走相同方法，没有固定帧号补丁；默认 demo 独立保留。

## 已实现

1. `racket_keypoints.py`：从当前视频拍框分割轮廓提取拍头中心/顶端；只有可见窄拍柄或拍喉时才记录对应点。被遮挡的柄末端保持缺失。这是经典几何推导，不是新训练的关键点网络。真人和镜中数据独立关联，保存源视频、候选和引导姿态哈希。
2. 镜面射线约束：将镜中像素射线变换回真实空间，计算双视角拍头位置。拒绝负深度、小基线夹角、射线距离超过4cm、拍头到握点距离与刚性模型相差超过8cm的结果。以主人体握点确定有向拍柄；仍受镜面和人体尺度估计误差影响。
3. `racket_direction.py`：用当前视频双视角证据估计手掌坐标内的固定拍柄偏差。每第五帧留出，只有三维方向误差和二维方向误差都改善才采用。先校准局部方向，再滤波世界方向，不能把世界方向滤波结果误当手掌内固定关系。实际握柄棱位仍未验证。
4. 初值修正：旧 `fit_shape` 初值有自由平移，后续序列优化却强制掌内握点；两阶段约束不一致。新初值直接锁定同一握点，并考虑关键点、手部质量及双视角拍柄，减少错误深度分支。
5. 序列拟合：关键点/轮廓/镜面/握点联合残差；冲突手部先验降权；SO(3) 角加速度平滑，原始手部方向误差保留在输出，不能只报告“修正后”指标。位置或方向不一致的帧明确标记待复核。
6. `racket_landmarks.py` / `dataset_racket_review.js`：各视频独立的稀疏校准入口。支持真人/镜中握柄末端、拍喉、拍头、同一物理 A/B 侧，方向键微调和清除遮挡点。无需逐帧人工校正。
7. 法线输出：`normal_camera`、有向0–180°夹角、原视频法线箭头及身份状态。对称拍框无法凭轮廓确认物理正反面；默认是连续模型法线，显示“正负待校准”。需要可辨识 A 侧标记和人工对应，并且重投影通过，才标记相应关键帧已校准；邻帧不自动冒充已确认。

8. `racket_quality.py`：候选与参考使用同一固定关键点对比。柄轴角 P95、拍头位置 P95/中位数、角加速度和缺失帧设回归门限；未通过时保留参考默认，候选写入独立文件供复核。首次生成没有参考时标记待复核，不声称已验证准确性。

## 自动流程与命令

```text
云 GPU：真人 SAM3D → 镜中 SAM3D → 双人物 SAM2
本地：镜面配准 → 握拍约束 → 原分辨率拍框 ROI
    → 拍柄关键点 / 镜面射线 → 手掌内方向校准
    → 同握点初值 / 球拍联合拟合 / SO(3) 平滑
    → 固定观测回归检查 → 默认结果 / 待复核候选 → Viewer
```

```sh
python3 -B viewer/video_import/racket_keypoints.py --dataset <dataset> --result <staged-result>
python3 -B viewer/video_import/fit_dataset_grip.py --dataset <dataset> --result <staged-result>
python3 -B viewer/video_import/audit_racket_motion.py <staged-result>/racket_poses.json --check
python3 -B viewer/video_import/audit_racket_direction.py <staged-result>/racket_poses.json \
  --keypoints <staged-result>/racket_keypoints.json --meta <staged-result>/mesh_meta.json
```

方向审计使用同一固定观测对比旧/新结果，避免用新拟合自证准确。`--check` 是严格全样本图像/方向门限；低置信度和遮挡样本仍可能未通过，应报告结果及待复核帧，不能解释为真实三维准确率。

## Viewer 与 API

在“镜面与球拍”展开项中：

- **版本**：当前默认 / 方向候选。切换时保留当前帧、镜面与球拍开关；候选未通过检查时明确显示待复核。
- **方向观测**：显示图像关键点和法线箭头。未确认物理正负时使用虚线。
- **◎ 球拍校准**：暂停当前清晰关键帧，选真人或镜中点。只填可见点。
- **A 侧固定物理标记已核对**：要求真实可识别标记说明，以及柄末端/拍头/A/B 点。镜中对应必须是同一物理侧；不是按屏幕左右命名。

`POST /api/videos/<id>/racket-landmarks` 校验视频哈希、分辨率、fps、帧号、点位和物理标记条件。在私有临时目录拟合，完成后保存候选和检查报告；检查未通过保留原默认姿态，运行失败保留原标注和姿态。保存后刷新球拍层，原视频时间保持不变。

标注格式：

```json
{
  "video_sha256": "当前视频 SHA-256",
  "image_size": [2560,1440],
  "fps": 25,
  "frames": [
    {
      "frame": 0,
      "points": {"handle_end": [100,200], "tip": [200,200]},
      "mirror_points": {},
      "face_correspondence_confirmed": false,
      "side_feature": ""
    }
  ]
}
```

此示例坐标只是契约示例，不能直接用于真实视频。
