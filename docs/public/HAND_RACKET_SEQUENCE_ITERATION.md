# 全片手—球拍联合拟合：第一轮

## 当前状态

实现了逐帧质量加权、整段关节/球拍联合求解和独立诊断 Viewer。250 帧均参与；本轮不读取手选关键帧清单，不按具体帧号修改权重或位置。初始球拍朝向沿用已有 v2，因此仍继承它的估计偏差。

**这是关节层面的候选，不是完成的握拍人体网格。** 默认 Viewer 未替换。下一阶段仍需将关节优化接入人体手部骨骼驱动，增加关节活动范围、自碰撞及真实网格与柄面的接触检查；当前点到圆柱面的残差不能验证这些性质。

## 数据与约束

1. 通过已有时间戳/画面映射将原分辨率 SAM full 输出对应到 Viewer 时间轴；重复使用的源帧降权。映射本身是估计，低置信度对应保留复核标记。
2. 自动结合手部解码器筛选、局部清晰度、双手距离、球拍与手腕的关联以及画面匹配差值赋权。权重是启发式可靠性，**不是置信概率**。局部清晰度也可能受到背景边缘影响。
3. 优化每帧刚性球拍旋转、握点及 21 个右手关节。手腕保持不动；掌指关节单轴调整上限 10mm，其他手指关节为 25mm。使用骨长保持、SAM 投影先验、球拍轮廓、指端到柄轴圆柱面及穿透惩罚。
4. 用手掌坐标下相邻握点/球拍朝向的连续性约束持续握持；长时间缺少可信证据时断开握持连续性。另有球拍运动平滑先验。当前只能区分“可能握持/未知”，**尚不能可靠识别松手或主动换握**。
5. 当前镜面几何不是实测可靠的多视角约束，故本轮未加入镜像损失，避免将标定误差强行传给手部。

手部二维目标来自 SAM，未被当成人工真值。画面重投影残差小，仍可能存在深度方向错误。

## 结果

所有轮廓统计使用相同观测集合（245 帧），不只统计通过筛选的帧。

| 指标 | 原片手部＋初始球拍 | 联合候选 | 原默认 v2 |
|---|---:|---:|---:|
| 轮廓残差中位数 px | 9.05 | 6.22 | 4.57 |
| 轮廓残差 P90 px | 16.87 | 11.79 | 9.69 |
| 相邻旋转 >45° 次数 | 3 | 0 | 3 |
| 接触先验残差中位数 mm | 16.69 | 0.48 | 不跨人体估计比较 |

最大骨长变化约 0.157mm，最大手指关节位移约 38.3mm（多个轴合成）。相对 SAM 手部投影的平均变化约 0.71px。217 帧触发至少一项复核条件，包含弱手部证据、较大的推断位移、帧对应不确定和轮廓残差等。接触先验未通过阈值的帧为 1；这**不是**其余 249 帧均握拍正确。

第一版联合解出现 38 次大旋转跳变，已保留为 rejected/unstable 对照。通用时序项加入后消除了此类跳变，但轮廓匹配仍比默认 v2 差，因此不满足替换条件。仍可能存在过平滑及拍面正反歧义。

## 文件与复现

代码：`viewer/sam3d/joint_fit/`。

```sh
python3 viewer/sam3d/joint_fit/prepare.py --data output/sam3d_cloud
OMP_NUM_THREADS=4 python3 viewer/sam3d/joint_fit/solver.py output/sam3d_cloud/joint_fit_v4/input.npz output/sam3d_cloud/joint_fit_v4/result.npz --steps 1600
python3 viewer/sam3d/joint_fit/report.py --data output/sam3d_cloud
python3 viewer/sam3d/joint_fit/export_review.py --data output/sam3d_cloud
python3 scripts/install_sam3d_viewer.py
```

输入依赖既有原片手部序列、帧映射、球拍候选与跟踪轮廓以及初始 v2 姿态。当前数据适配器针对右手、1280×720 Viewer / 2560×1440 原片合同；求解器支持不同帧数、内参与时间戳，但尚未验证跨人物、左手持拍或其他拍摄机位的泛化效果。不是可直接处理任意新视频的一键产品。

诊断入口：`http://127.0.0.1:8767/joint_fit_v4/viewer.html`。包含原图投影、可旋转三维手部关节、初始估计叠加和下一待复核帧。原 Viewer 球拍区只在候选报告存在时显示该链接。

输出：`output/sam3d_cloud/joint_fit_v4/` 中的 `input.npz`、`result.npz`、`quality.json`、`report.json`、`viewer_data.json`、`joint_review.mp4`、`overview.jpg`。

## 验证与限制

6 项新增测试覆盖刚性旋转、接触距离坐标不变性、时间戳异常、长缺失段断开、无证据状态及手腕/手指位移边界。另执行旧球拍/握持/坐标测试、JS 语法检查及输出数组、HTTP 资源检查。离线抽样图进行视觉检查。未自动操作浏览器页面；交互和不同屏幕布局未通过浏览器实测。

## 完整 Viewer 接入（候选模式）

新增 `viewer/sam3d/joint_fit/build_full_viewer.py`，运行后生成独立的完整人体 Viewer：

`http://127.0.0.1:8767/joint_fit_v4/full/viewer.html`

- 250 帧原分辨率重跑的人体网格、联合球拍、优化手部关节使用一致的 SAM 相机坐标。逐帧验证原始手腕与优化输入一致、柄局部锚点变换正确、拍框投影与求解结果一致。
- Wilson 网格直接使用联合结果的刚性变换，不再额外套用旧版固定掌内偏移。
- 橙色手部关节采用透视叠加，明确与尚未变形的手指网格区分；二维视频也显示对应的优化关节。
- 候选页默认灰模，关闭旧邻帧贴图缓存与镜面贴图。可切换为当前视频投影，但未验证其纹理贴合质量。原片人体未额外平滑，姿态选择锁为原始模式，避免将同一数据误称为不同平滑结果。
- 候选页不读取原版浏览器保存的球拍数据，不允许混入旧版模型姿态；提供返回原版链接。原版网格与默认球拍 JSON 保留。
- 原 Viewer 球拍面板新增“完整 Viewer · 联合候选”入口，资源存在时显示。

复现：`python3 viewer/sam3d/joint_fit/build_full_viewer.py`。该本地预览包引用同一视频和模型资产，使用绝对符号链接；**不能直接作为远程 Docker 发布包**，远程发布时须解析并复制所需资源。

### 下一步优先级

1. **统一观测来源**：球拍检测/跟踪直接在同一原片解码序列运行，人体和球拍共用源帧 ID 与 PTS；Viewer 输出时统一重采样，替代目前估计的新旧帧映射。
2. **改进视频贴合**：在同一观测集合上约束轮廓残差，增加柄尾/柄轴观测；避免用更大的接触权重换取更差的拍面投影。现阶段目标至少不劣于基线中位数 4.57px/P90 9.69px，同时保留不确定标记。
3. **接入真实手部骨骼驱动**：将独立关节 XYZ 优化改为 MHR 手部关节参数优化，检查活动范围、网格穿透和指腹接触后，才更新手指表面。不能把当前关节线直接称为已完成手网格重建。
4. **更新正式默认**：全片比较投影、旋转连续性、手部变化幅度和接触有效性，满足条件后再切换默认数据。不能仅凭“无 >45° 跳变”判断准确。

本次验证包含全片坐标/投影断言、HTTP 资源、JS 语法、原球拍和坐标测试，并查看了离线完整人体渲染。页面交互尚未自动化实测，不声称已在浏览器中完成视觉验收。
